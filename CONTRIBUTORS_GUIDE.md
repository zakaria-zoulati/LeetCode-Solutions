# LeetCode-Solutions Contributor Guide

Welcome, and thank you for your interest in contributing to **LeetCode-Solutions**.

The goal of this repository is to become a comprehensive collection of solutions for LeetCode problems, covering many programming languages, including **Java, C++, Python, and more**.  

Everyone is welcome to contribute.

---

## How to Contribute

- Fork the repository and create a new branch for your changes.  
- Open a Pull Request (PR) when your changes are ready.  
- All PRs are reviewed before merging to ensure quality and consistency.

You can contribute by:

- Adding solutions in new programming languages  
- Improving existing solutions  
- Adding explanations, comments, or better formatting  

Please avoid:

- Adding unrelated files  
- Duplicating existing solutions unnecessarily
